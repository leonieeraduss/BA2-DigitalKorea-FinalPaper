# Requirements

## Software

- Orange Data Mining: version 3.39.0
- Python: 3.x (used within Orange)

## Python Packages

The following packages are required for the Python preprocessing step:

- kiwipiepy (Korean tokenizer)
- pandas
- numpy
- re (standard library)
- collections (standard library)

## Additional Resources

- Custom Korean stopword list (`stopwords.txt`)

## Notes

All main analysis steps are performed within Orange Data Mining. Python is only used for preprocessing Korean text (tokenization and cleaning).
